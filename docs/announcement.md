## 中文

我给 Typora 做了一个轻量公式与笔记增强插件：单击公式引用，就能在原处预览被引用的公式；也能全文整理独立公式、一键插入带分隔线的蓝色 NOTE 讲解块，以及批量调整标题层级。

一个 JavaScript 文件，零运行时依赖，带中英文安装说明和 MIT 许可证。适合读论文、写推导和做技术笔记的朋友。

项目：https://github.com/guan695/typora-equation-preview
欢迎试用、反馈；如果有帮助，也欢迎 Star。

## English

I built a lightweight Typora enhancement for math-heavy Markdown: click an equation reference to preview it in place, format standalone display math, insert reusable NOTE callouts, and demote selected headings.

One JavaScript file, zero runtime dependencies, English/Chinese setup instructions, and an MIT license.

Try it: https://github.com/guan695/typora-equation-preview
Feedback and stars are welcome if it helps your workflow.
